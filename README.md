# MS_iSTAY

This repository contains three datasets and two sets of R source code associated with the paper "A continuum of information-based temporal stability measures and their decomposition across hierarchical levels" by Chao et al. (2026).

The R scripts provide the analyses and functions needed to reproduce all figures in the main text and Supporting Information, including calculations of information-based temporal stability and synchrony measures.

## Data

The analyses are based on biomass time-series data from the Jena Experiment. Three datasets are provided:

### Data_Jena_20_metacommunities

Biomass time series data from 2003 to 2024 (22 years) for the constituent communities within each of the 20 metacommunities in the Jena Experiment. The dataset contains a list of 20 data frames, each with plots (communities) as rows and time points as columns.

All 76 plots (communities) are grouped into 20 metacommunities according to block identity and species-richness level. Each metacommunity consists of three or four plots with the same species richness but different species compositions.

### Data_Jena_462_populations

Biomass time series data for 462 populations across 76 plots from 2003 to 2024 (21 years, excluding 2004). The dataset is a population-by-time data frame with 462 rows and 21 columns. Each row represents a population, and each column represents one year of biomass data.

### Data_Jena_76_community_populations

Biomass time series data of 76 communities in the Jena Experiment. Each community dataset contains the 21-year biomass time series data for all species sown within each plot. Because the number of species sown per plot ranges from 1 to 16, the number of populations within a community also ranges from 1 to 16.

This dataset contains the same data as `Data_Jena_462_populations`, but is organized for analytical convenience into a list of 76 communities, each containing a population-by-time biomass data frame for its constituent populations.

The datasets are provided in the `data/` folder and can be loaded directly by the R scripts.

## Repository contents

1. **R_code_for_main_document.R:** R code for performing the analyses and generating all figures (Figures 1 to 4) in the main text of Chao et al. (2026).
2. **R_code_for_supporting_information.R:** R code for performing the analyses and generating all figures in Appendices S1 to S5 of Chao et al. (2026). 
3. **data/:** Datasets used for the analyses and figures.
4. **figures/:** Figures generated by the R scripts.
5. **MS_iSTAY.Rproj:** RStudio project file.

## Access information

All datasets and source code are also available through the R package **iSTAY** (information-based stability and synchrony measures), available from [CRAN](https://cran.r-project.org/web/packages/iSTAY/index.html).

An online version is also available at [iSTAY Shiny App](https://chao.shinyapps.io/iSTAY/).

The biomass data from 2003 to 2023 were retrieved from [Jena Experiment Data (2003–2023)](https://jexis.idiv.de/ddm/Data/ShowData/624), while the 2024 data were obtained from [Jena Experiment Data (2024)](https://jexis.idiv.de/ddm/Data/ShowData/695).

## Requirements

The scripts require R and the packages used for data analysis and visualization, including `tidyverse`, `lmerTest`, `gridExtra`, `ggpubr`, `mvtnorm`, `RColorBrewer`, and `ggtext`.

## Reproducing the figures

Open `MS_iSTAY.Rproj` in RStudio and run `R_code_for_main_document.R` or `R_code_for_supporting_information.R` to generate the corresponding figures.

The output figures are saved in the `figures/` folder.
